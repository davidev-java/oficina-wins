# oficina-wins

Landing page de David Oliveira: criação de sites e sistema de gestão para oficinas
mecânicas e lojas de autopeças (Minas Parts, Expominas, Belo Horizonte).

Stack: TanStack Start, React 19, Tailwind CSS 4 e Vite.

## Rodar localmente

```sh
bun install
bun run dev
```

## Build

```sh
bun run build
```

O deploy é feito na Vercel.
